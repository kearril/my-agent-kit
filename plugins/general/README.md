# General Plugin (通用元能力套件)

面向日常讨论、科研、调研、办公协作与跨场景通用对话的基础元能力插件。建议在 OMP 中全局常驻启用。

## 技能与命令清单

| 命令入口 | 对应技能 | 核心定位与说明 |
| :--- | :--- | :--- |
| `/general:grill-me` | `grill-me`, `grilling` | **苏格拉底式高强度质询**：将方案建模为决策树，逐轮逼问消除隐性假设与思维盲区 |
| `/general:wait-what` | `wait-what` | **即刻叫停与通俗重述**：当信息太绕或听不懂时叫停，要求用大白话交代背景并重新阐述 |
| `/general:handoff` | `handoff` | **跨会话状态交接**：将当前长对话核心结论与待办打包存盘，供新会话无缝续接 |
| `/general:to-questionnaire` | `to-questionnaire` | **结构化信息挖掘问卷**：生成面向协作者的异步提问问卷，挖掘跨方决策信息 |
| `/general:research` | `research` | **一手课题深度调研**：派发后台 Agent 深入权威一手资料与论文，产出带引用的 Markdown 报告 |
| `/general:teach` | `teach` | **体系化交互式教学**：以当前目录为教学工作区，多会话交互学习并沉淀学习档案与术语表 |
| `/general:retro` | `retro` | **会话复盘与反思**：分析刚刚结束的会话中的沟通偏差，提炼知识沉淀与 Prompt 改进项 |
| *(模型自主)* | `writing-for-agents` | **Agent 规范编写心法**：关于 Context 负载预算、渐进式披露与指令设计的核心指南 |
