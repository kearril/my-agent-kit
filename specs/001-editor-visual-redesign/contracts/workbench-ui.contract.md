# Contract: Workbench UI Component Hierarchy & Interfaces

**Module**: `src/dev/`

## Component Structure

```text
LocalEntryEditorApp (src/dev/editor.tsx)
├── StudioToolbar (src/dev/components/StudioToolbar.tsx)
└── WorkbenchBody (div.workbench-body.pane-[mode])
    ├── NavSidebar (src/dev/components/NavSidebar.tsx)
    │   ├── SearchInput
    │   ├── FilterTabs
    │   ├── TypeSelect
    │   └── SpecimenEntryList
    ├── EditorPane (main.workbench-editor-pane)
    │   ├── CompactHeader (src/dev/components/CompactHeader.tsx)
    │   │   ├── PrimaryRow (Title, Slug, DraftToggle, ExpandButton)
    │   │   └── CollapsibleDrawer (Summary, Dates, TagPicker, Category, LinkRepeater, RelatedPicker)
    │   ├── MarkdownToolbar (src/dev/components/MarkdownToolbar.tsx)
    │   │   └── FormatButtons (Bold, Italic, Code, Link, List, Quote, CodeBlock)
    │   ├── BodyTextarea (textarea#field-body with Tab/Indent and Shortcuts support)
    │   └── ActionStatusBar (Save status, Live entry link, Save button)
    └── ArticleBinderPreview (src/dev/components/ArticleBinderPreview.tsx)
        ├── PreviewHeader (Status tag, Refresh indicator)
        └── PreviewIframe (srcDoc generated by buildPreviewDocument)
```
