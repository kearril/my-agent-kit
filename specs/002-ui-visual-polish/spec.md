# Feature Specification: UI Visual Polish & Reading Comfort Enhancement (UI 视觉打磨与阅读舒适性增强)

**Feature Branch**: `002-ui-visual-polish`

**Created**: 2026-08-26

**Status**: Draft

**Input**: User description: "我们下一阶段是对UI视觉进行精细打磨与增强，重点提升UI的视觉效果，交互体验和长时间阅读舒适性。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 沉浸式与高舒适度的文章长文阅读体验 (Priority: P1)

作为一名数字花园的访客或深度阅读者，我希望在进入任何公开条目页（Prompt、Skill、MCP、Website、Project 或 Note）时，能够享受温润不刺眼、排版层次清晰、排印间距舒适的“长文装订册”（Reading Binder）阅读界面，在阅读数千字的长篇笔记或复制复杂提示词时双眼不感到干涩和疲劳。

**Why this priority**: 数字花园的核心资产是内容。文章页是访客停留时间最长的核心触点，直接决定了站点的专业度、审美质感与留存率。

**Independent Test**: 访问任意一篇包含长文、代码块、引用块、列表及前后关联项的条目页，检查页面是否呈现为温润的装订手账纸本结构，正文字距与行高是否舒适易读，代码块是否柔和折行且支持一键无缝复制。

**Acceptance Scenarios**:

1. **Given** 访客进入任意公开条目页，**When** 浏览正文时，**Then** 正文区域最大宽度舒适受控（约 65~75 字符舒适行宽），背景呈现柔和的特种工程纸品底色与精细底纹，排版字体间距与行高（1.75~1.8）确保长时间连续阅读无眩光、无视觉压迫感。
2. **Given** 条目包含代码块、配置文本或长 Prompt 提示词，**When** 访客查看该代码块时，**Then** 底色为柔和温润的工程浅色背景而非刺目高对比度暗黑块，文本自动软折行不产生破坏性横向滚动条，右上角配备清晰触控区（不小于 44px）的一键复制按钮，点击后呈现清晰图标视觉确认反馈。
3. **Given** 条目包含摘要、元数据、分类标签与反向链接，**When** 访客查看条目头部与底部时，**Then** 头部呈现手账档案盒式摘要与复古印章戳记，底部呈现清晰的双向关联甲板与来源反向链接，层级分明且无视觉杂乱。

### User Story 2 - 灵敏触感与流畅的探索搜索交互 (Priority: P1)

作为一名访客，我希望在首页或探索区域（Explore）浏览、搜索或筛选各类花园条目时，控件具有真实的物理按压触感与即时反馈，筛选切换丝滑流畅，弹窗详情阅读无遮挡且方便进出。

**Why this priority**: 探索模块是访客寻找所需 Prompt、工具和笔记的主要工具，顺滑、有触觉反馈的交互能够极大地提升浏览愉悦感。

**Independent Test**: 在探索区域快速输入搜索关键词、切换不同类型标签页、点击卡片展开详情弹窗，测试交互反馈时间、焦点管理及关闭流畅度。

**Acceptance Scenarios**:

1. **Given** 访客在探索区域输入搜索关键词，**When** 连续键入时，**Then** 搜索即时过滤且带有平滑防抖响应，匹配结果数量实时更新，提供一键清空关键词操作，空结果时展示友好且风格统一的手作插画与重置建议。
2. **Given** 访客切换资产类型标签（如 Prompt、Skill、Website、Note），**When** 点击标签芯片时，**Then** 标签具备清晰的高亮与硬边按压位移反馈，列表平滑过滤且不引发布局剧烈跳动。
3. **Given** 访客点击卡片查看大卡片详情弹窗，**When** 弹窗打开时，**Then** 弹窗以直角硬边纸卡形式清晰呈现，背景页面滚动自动锁定，支持点击遮罩、点击关闭按钮或按下 `Esc` 键平滑关闭，关闭后焦点正确恢复至原卡片。

### User Story 3 - 首页各区块的工坊手作与视觉节奏增强 (Priority: P2)

作为一名初次访问数字花园的访客，我希望在滚动浏览首页各个区块时，能感受到鲜明生动且克制的手账工坊美学（如和纸胶带过渡条、标本明细卷宗、微倾斜便签卡与图钉质感），获得富有节奏感的视觉探索体验。

**Why this priority**: 首页是站点的门面，决定了访客的第一视觉印象与探索欲，合理的区块节奏与手作装饰能够建立独特的站点辨识度。

**Independent Test**: 从顶部向下滚动浏览首页的 Hero、精选、最新动态、随笔与探索区块，检查区块之间的过渡胶带、明细卷宗点线排布以及便签卡片的轻微悬停归位动效。

**Acceptance Scenarios**:

1. **Given** 访客滚动浏览首页，**When** 跨越不同主题区块时，**Then** 区块分界处呈现醒目且克制的和纸胶带过渡条（如斜纹手作封口胶带），强化工坊拼接与分区节奏。
2. **Given** 访客查看最新动态或笔记列表，**When** 鼠标悬停在单行明细条目上时，**Then** 该行呈现整行温和高亮与微位移，中间的点线（Dot-leader）连接清晰指引日期与分类徽章。
3. **Given** 访客悬停于首页便签卡片，**When** 鼠标移入时，**Then** 卡片从微倾斜（≤ 2°）平滑归位至正角度并产生硬边阴影外扩，位移动画自然且无弹跳或布局挤压。

### User Story 4 - 全站触控目标、键盘焦点与无障碍阅读友好性 (Priority: P2)

作为一名使用键盘导航、移动端设备或开启了减弱动效偏好的用户，我希望全站所有可交互元素都拥有不小于 44px 的舒适触控面积、鲜明的键盘焦点环，并在弱动效模式下保持稳定沉静。

**Why this priority**: 视觉增强必须以无障碍与多端体验为底线，确保所有设备和各类习惯的用户都能舒适使用。

**Independent Test**: 在移动端屏幕尺寸下测试按钮与链接点击，使用 `Tab` 键遍历全站所有可聚焦元素，并在系统开启 `prefers-reduced-motion` 情况下检查所有过渡效果。

**Acceptance Scenarios**:

1. **Given** 用户使用 `Tab` 键在页面内导航，**When** 焦点落在任意按钮、链接或输入框上时，**Then** 元素呈现高对比度的双层硬边焦点指示环（如纯黑外框加亮色内阴影），焦点轨迹清晰连贯。
2. **Given** 用户在移动端（手机/平板）浏览站点，**When** 点击任何按钮、标签或卡片时，**Then** 点击热区均达到 44px × 44px 以上，页面无横向溢出滚动，文本字体大小保证无需缩放即可清晰阅读。
3. **Given** 用户系统设置了减弱动效（`prefers-reduced-motion: reduce`），**When** 浏览页面与触发交互时，**Then** 所有的旋转、位移与阴影变化均自动减弱或转为即时切换，杜绝可能引起眩晕的动态位移。

---

### Edge Cases

- **极长单字/连续无空格字符**：在长 URL、长英文单词或复杂代码指令中，正文与卡片必须智能软折行，绝对禁止冲破纸张容器或产生横向滚动条。
- **无图/极简短条目**：没有配图或正文极短的便签，版面必须保持完整平衡，不能出现大面积空旷塌陷或样式断层。
- **超小屏幕设备（如 360px 宽度手机）**：顶部导航、工具栏、筛选标签与元数据徽章自动换行或自适应重排，禁止文字被截断或按钮挤压重叠。
- **超宽屏幕（如 2K/4K 显示器）**：正文阅读区严格约束在最大舒适宽度（960px）并居中，背景网格平铺无接缝断裂。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 统一全站所有界面的视觉语言为**俏皮野兽派与手账工坊质感**，全站所有卡片、容器、输入框、按钮必须采用直角无圆角（`border-radius: 0`）、纯黑粗边框（2.5px ~ 4px）与实色硬边偏移阴影（4px ~ 8px），禁止出现任何模糊阴影、渐变色或柔和灰色。
- **FR-002**: 系统 MUST 将全站正文阅读区域的底色统一为温润护眼的特种工程纸品底色（`--paper` / `--paper-cotton`），搭配 24px × 24px 微弱工程方格网底纹，确保长时间阅读时眼部无眩光和视觉疲劳。
- **FR-003**: 系统 MUST 优化文章正文排版节奏，正文字体行高设定在 1.75 至 1.8 之间，段落间距、标点挤压与中文/英文混排间距协调舒适，单行字数严格控制在约 65~75 个字符的最佳舒适行宽。
- **FR-004**: 系统 MUST 将所有代码块、提示词卡片与配置文本块重构为浅色工程纸底色（`#f0eae1`）与深墨色文字，设置智能软折行以消除破坏排版的横向滚动条，并配备右上角一键复制控件与即时 SVG 视觉反馈。
- **FR-005**: 系统 MUST 在公开条目头部提供结构清晰的手账“摘要档案盒（Summary Box）”与分类色标徽章，在底部提供清晰的双向关联图谱甲板与反向链接列表。
- **FR-006**: 系统 MUST 为所有可交互元素（按钮、卡片、标签、导航链接）提供完整的物理按压反馈（Hover 微位移加阴影扩大、Active 压平减阴影、Focus-visible 高亮指示环）。
- **FR-007**: 系统 MUST 在首页不同主题区块之间采用鲜明且克制的和纸胶带过渡条（如手作斜纹封口胶带）进行视觉切分，增强页面探索节奏。
- **FR-008**: 系统 MUST 优化最新动态与笔记列表的“标本明细卷宗（Ledger Table）”排布，采用整行高亮与点线连接（Dot-leader），提供紧凑清晰的快速索引视图。
- **FR-009**: 系统 MUST 优化探索模块（Explore）的搜索与标签筛选体验，支持实时防抖过滤、计数展示、一键清空与空状态手作插画提示。
- **FR-010**: 系统 MUST 支持大卡片详情弹窗（Modal Dialog），弹窗打开时锁定背景滚动并捕获键盘焦点，支持遮罩点击、关闭按钮与 `Esc` 键快捷退出。
- **FR-011**: 系统 MUST 保证全站交互元素具备不小于 44px × 44px 的触控热区，并在移动端、平板与桌面端实现完美的响应式自适应排版，杜绝任何视口溢出。
- **FR-012**: 系统 MUST 严格遵守 `prefers-reduced-motion: reduce` 系统偏好，在开启减弱动效时禁用或平滑淡化所有旋转、位移和位移动画。
- **FR-013**: 系统 MUST 严禁使用 Emoji 或直接输入的 Unicode 字符作为页面装饰符号，所有装饰图标与反馈图标一律使用清晰的 SVG 图标或纯 CSS 几何图形。

### Key Entities *(include if feature involves data)*

- **Reading Binder (长文装订册)**: 公开条目长文的主体容器实体，具有最大宽度约束（960px）、特种纸背景、方格底纹、档案盒头部、正文排版区与底部反向链接甲板。
- **Washi Tape Strip (和纸胶带过渡条)**: 区块间的物理分隔实体，具有手作斜纹、微倾斜角度（≤ 2°）、粗墨线边框与鲜明对比色。
- **Specimen Ledger Row (标本明细卷宗行)**: 列表展示实体，包含标题、类型徽章、时间戳、点线连接符与整行悬停高亮状态。
- **Explore Filter State (探索筛选状态)**: 探索区域的交互实体，包含当前搜索关键词、选中的类型标签、排序方式以及匹配条目集合。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 访客在长文条目页（含 3000 字以上及多段代码块）的阅读舒适度显著提升，页面在 2K、1080P 及移动端屏幕上均保持 65~75 字符的黄金阅读行宽与 1.75 以上舒适合理行高。
- **SC-002**: 页面中所有代码与提示词展示块 100% 实现无横向滚动条的智能软折行，一键复制控件在点击后 100ms 内提供清晰的视觉成功反馈。
- **SC-003**: 全站所有可点击控件（按钮、链接、标签、筛选按钮）在移动端 100% 达到 44px × 44px 以上的最小触控面积，无误触与紧贴问题。
- **SC-004**: 全站所有可交互元素 100% 具备高辨识度的键盘 `focus-visible` 焦点指示环，使用键盘 `Tab` 键可完整遍历和操作所有功能。
- **SC-005**: 探索模块在用户键入搜索词后 300ms 内完成实时平滑过滤，结果响应流畅无卡顿与页面布局跳动。
- **SC-006**: 在开启 `prefers-reduced-motion: reduce` 的环境下，全站所有卡片位移与旋转动效 100% 降级为平滑无位移动画，无突兀跳跃。
- **SC-007**: 生产静态构建（`pnpm build`）与全站自动化测试（`pnpm test`）100% 绿灯通过，零控制台警告与零样式重叠报错。

## Assumptions

- 站点继续采用 Astro 静态生成为主、React 仅用于局部 Island（如 `ExploreIsland.tsx`）的架构原则。
- 视觉风格完全继承 `docs/DESIGN.md` 中定义的方案 A（复古手账与档案工坊），色盘与设计 Token 保持单一事实来源。
- 所有视觉优化均在现有 CSS Token、组件与页面模板上进行精细化迭代与增强，不破坏现有的不可变 slug 与内容集合架构。
